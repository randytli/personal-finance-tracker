## Single Serve action, after approval and passing prechecks

In Windows **Administrator PowerShell**, run exactly once:

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' serve --bg --https=443 http://127.0.0.1:3000
```

Expected effect: one **tailnet-private** HTTPS listener on Windows Tailscale port 443, forwarding `/` to the existing Windows loopback web app. The `--bg` setting persists across a later Tailscale/device restart, but this action includes **no restart**. The command may arrange a public CA certificate for the new name; it does not require `tailscale cert`. Tailscale [documents Serve as tailnet-only and subject to access controls](https://tailscale.com/docs/features/tailscale-serve), and [documents these CLI flags and persistence](https://tailscale.com/docs/reference/tailscale-cli/serve). Do not run `tailscale funnel`, use the old `/f/serve` link, change tailnet policy, advertise routes, alter Docker bindings, or open router/API/DB ports. If the CLI requests another prerequisite or shows an unexpected hostname, stop without accepting it.

Immediately inspect:

```powershell

& 'C:\Program Files\Tailscale\tailscale.exe' funnel status
```

Require exactly one Serve `TCP` entry for `443` with `HTTPS: true` and one `Web` handler keyed **`pft-host.tailc4d964.ts.net:443`**, path `/`, proxy `http://127.0.0.1:3000`.
