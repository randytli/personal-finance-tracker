## Exact prerequisite and decision

[Tailscale's HTTPS guide](https://tailscale.com/docs/how-to/set-up-https-certificates) says to use Admin Console → **DNS**, ensure **MagicDNS** is enabled, then under **HTTPS Certificates** select **Enable HTTPS** and acknowledge the public certificate-name disclosure. [Serve requires HTTPS certificates](https://tailscale.com/docs/features/tailscale-serve). The URL emitted by the earlier Serve CLI opens a Serve consent flow that may enable unmet requirements; do not use that flow for this isolated HTTPS action. Do not run `tailscale cert` or a Serve command in this stage.

Enabling HTTPS is a **tailnet-wide ability to request certificates**, not an application listener. Tailscale's guide says an issued certificate's full device DNS name enters the public, append-only Certificate Transparency (CT) ledger. The intended Windows certificate name is **`pft-host.tailc4d964.ts.net`**. The opaque tailnet portion does not identify the owner by itself, but `pft-host` will be publicly visible; other tailnet devices could also have their names logged if they later obtain certificates. Tailscale says certificate and ACME private keys are generated and stored locally. Tailnet network grants still control access to Serve; a public CT entry alone does not grant access. Once published, the CT name cannot be removed by disabling HTTPS or Serve. Tailscale also says disabling HTTPS does not revoke already issued certificates and a single machine certificate cannot be invalidated in the console. [HTTPS guide](https://tailscale.com/docs/how-to/set-up-https-certificates); [Serve access controls](https://tailscale.com/docs/features/tailscale-serve).

The [deployed FastAPI allowlist](PFT_PHASE_2_M1_ORIGIN_REPLACEMENT_ACTION_2026-09-25.md) now contains **`https://pft-host.tailc4d964.ts.net`** in place of the old HTTPS Origin, alongside the two localhost origins. Its API health, proxy-Origin, localhost, and preservation gates passed on 2026-09-25. This packet assumes the owner accepts publication of the exact new name above when Serve later obtains its certificate.
